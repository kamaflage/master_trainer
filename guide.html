Chapter 00 · Overview
What is
Master Trainer?
A structured learning system that lives entirely in your browser. It turns any LLM into a personalised adaptive tutor — with no API key, no backend, and no lock-in.

The Core Idea

Every LLM session is ephemeral — the tutor forgets everything when the tab closes. Master Trainer solves this by acting as your persistent layer. It stores your curriculum, tracks your confidence across every topic, and generates a precisely-crafted session prompt that tells the LLM exactly who you are, what you've already covered, and how you learn best.

You paste the prompt into Claude, GPT, Gemini, or any local model. Run the session. Paste the response back. The app parses your confidence score automatically and updates your progress.

The Three-Step Loop

1
Pick a lesson
Browse your curriculum. Each lesson shows your current confidence level, status, and estimated time. The dashboard surfaces where to start based on your in-progress work.
2
Copy the prompt
Open any lesson, select your LLM model, and tap Copy Prompt. Paste into any AI chat. The prompt is pre-loaded with your name, role, context, persona preference, and current confidence — the LLM knows everything it needs.
3
Log the session
After your session, paste the LLM's full response into Log Session. The app auto-extracts your confidence score, summary, and recommended next topic. Or quick-log: Solid / Shaky / Confused.
💡 Zero dependency — No API key required. The app generates prompts you manually paste. Works with any LLM interface: Claude.ai, ChatGPT, Gemini, local Ollama, anything.
Chapter 01 · Profiles
Profiles &
Multi-Learner
Every learner gets their own profile — with their own curriculum, progress, streak, and persona preferences. Profiles are fully isolated and portable.

Creating a Profile

On first launch you'll see the splash screen. Hit + New Profile. Fill in:

Name
Your first name. Woven into every prompt — the tutor will address you directly.
Role
Your job title or domain. e.g. RPA Developer, Data Engineer. Shapes the prompt's example context.
Context
A sentence about your work. e.g. I build automation bots at a telecom company. The more specific, the better the examples.
Avatar
A single emoji. Purely cosmetic — but it shows up everywhere.

Why Role + Context Matter

As of v1.8, the session prompt is fully profile-aware. Your Role and Context are used to generate the [ROLE] and [ILLUSTRATE] blocks dynamically. If you fill them in, the tutor will say things like: "Show one concrete example that Chris could encounter in their work as an RPA Developer (building automation bots at a telecom company)."

If you leave them blank, it falls back to generic technical examples — still useful, just less targeted.

💡 Multiple profiles — Colleagues, family members, or different learning tracks can each have their own profile. Switch from the splash screen or the profile icon in the top bar. Progress never bleeds between profiles.

Curriculum Packs on Creation

During setup, check Include RPA Tech Lead Pack to start with both the Transferable Core (6 lessons) and the RPA Phase 1 pack (12 lessons). You can always import additional packs later via the Import button.

Importing Custom Packs

Hit the Import button in the top bar and select Import Pack (JSON). A pack is a JSON array of lesson objects. The app deduplicates by id — importing the same pack twice is safe. As of v1.8 it tells you exactly how many were added and how many were skipped.

Adding a Custom Lesson

In any lesson's detail view, tap ✏️ Edit. Or open the lesson editor from the sidebar context. You can set title, track, why, domain, mastery criteria, prerequisites (comma-separated IDs), and even a full prompt override if you want complete control over what gets sent to the LLM.

⚠️ Prerequisites — A yellow banner appears on a lesson if its prerequisites haven't hit confidence ≥ 3 yet. This is advisory, not blocking — you can open any lesson in any order.
Chapter 03 · Sessions
Running a
Session
A session is one lesson, one LLM, one conversation. The prompt is a two-phase state machine — the tutor teaches first, then evaluates. Here's exactly how it works.

The Session Prompt Structure

Every generated prompt has six labelled blocks:

[ROLE] ← who the tutor is + your style preference + model hint [IDENTITY] ← your name, role, and work context [SESSION] ← lesson title, track, difficulty, current confidence [TEACH] ← analogy-first explanation + domain-relevant example [ILLUSTRATE] ← one concrete worked example from your domain [TEST] ← one application question — then HARD STOP

After you answer the test question in the LLM chat, the tutor enters Phase 2: it evaluates your answer (Solid / Partial / Confused), gives you a reinforcement task, asks you to self-rate 1–5, then outputs the results block.

The Results Block

At the end of Phase 2, the tutor outputs exactly this:

=== SESSION RESULTS === CONFIDENCE: 4 SUMMARY: Covered regex character classes with a real CB bot parsing example. NEXT: Regex — Groups and Capturing MODEL: claude-sonnet-4-5 === END ===

Paste the full LLM response into Log Session → Parse & Log Session. The parser extracts all four fields. Your lesson confidence, status, history, and streak update automatically.

Model Selector

Inside any lesson's Session Prompt panel, select from claude, gpt, gemini, local, or notebooklm. The first four add a model-specific note to the [ROLE] block: Gemini gets a large-context instruction, GPT gets an efficiency note, local models get a brevity constraint.

Selecting notebooklm generates a completely different prompt format — not a state machine, but a single-shot source-grounded Q&A prompt designed for NotebookLM. See the NotebookLM Mode section in Tips & Advanced for how to use it.

Quick Log

If you did the session but don't have the full response, use the quick log buttons: ✅ Solid (5), ⚡ Shaky (3), 🔄 Confused (1). These skip the parser and log directly with the selected confidence level. You can still add a manual note.

💡 The hard stop matters — The prompt instructs the tutor to stop after asking the test question and wait for your reply. If your LLM ignores this and keeps going, add to the start of the session: "Strict mode: follow the state machine exactly."
Chapter 04 · Personas
Tutor
Personas
A persona is a tutor style preset. It gets embedded in the [ROLE] block of every prompt. Pick the one that matches how you learn, or write your own.

The Four Presets

⚡Direct
Peer-level, no preamble. Straight to examples. Tells you when you're wrong. Best for experienced learners who want density over scaffolding.
🎓Mentor
Step-by-step, encouraging. Builds confidence alongside knowledge. Best when you're in unfamiliar territory and need progressive scaffolding.
🧭Explorer
Socratic. Asks questions, makes you discover answers. Best for conceptual topics where insight matters more than procedure.
🏋️Coach
Practical outcomes only. No theory without application. Pushes you when comfortable. Best for applied skills you need to use immediately.

Custom Persona

During profile creation (or later via the profile editor), scroll past the four presets and write your own tutor description in the free-text field. This text replaces the preset in [ROLE] verbatim — you have full control.

Example: "Blunt. Uses Bell telecom examples. If I'm wrong about regex, say so immediately and show the correct version. No praise for partial answers."

💡 Switching personas — You can't switch persona mid-session (the prompt is already copied). But you can edit your profile before the next session. The change takes effect immediately on the next prompt you generate.
Chapter 05 · Tracking
Progress
& Tracking
Every session you log updates your lesson confidence, status, streak, and history. The dashboard surfaces this at a glance. Nothing is opaque.

Confidence Scale

1 — Lost
Fundamental concepts unclear. Need a different approach entirely.
2 — Get the idea
Conceptual grasp, can't apply yet. More sessions needed.
3 — Can explain
Can articulate the concept. Prerequisites cleared at this level.
4 — Can apply
Lesson marked Complete at this level. Can use it in real work.
5 — Could teach it
Full ownership. Highest confidence. Streak and avg-confidence metrics use this scale.

Lesson Status

Lessons transition automatically: not-started → in-progress (first session logged) → complete (confidence ≥ 4). Status is used by the dashboard to surface suggestions and by the sidebar filters.

Session History

Every logged session is stored in the lesson's history — date, confidence, model used, summary, and AI-recommended next topic. The detail view shows the last 8 sessions inline; tap + N more to expand. Older sessions are never deleted unless you wipe the profile.

Dashboard Stats

The dashboard shows: lessons complete, in progress, total sessions logged, current day streak, and average confidence across all lessons you've touched. The streak increments when you log at least one session per calendar day.

Suggested Next

Below the stats, the dashboard surfaces up to 3 suggested lessons — in-progress lessons first, then not-started ones. This isn't AI-driven; it's a simple prioritisation: keep momentum on what you've started before picking up something new.

⚠️ Auto-export trigger — After every 5 sessions, the app prompts you to export. Don't dismiss it. Your data lives in localStorage — if you clear browser data, it's gone. Export early, export often.
Chapter 06 · Export & Data
Export,
Import & Data
Your data never leaves the browser unless you choose to export it. No cloud, no account. Portability is a first-class feature — your profile JSON is human-readable and importable on any device.

Exporting a Profile

Hit Export in the top bar. A JSON file downloads to your device — named with your profile name and today's date. This file contains your full curriculum state: every lesson, every confidence score, every session history entry, and your persona settings.

Importing a Profile

On the splash screen or via Import → Import Profile (JSON), select the exported file. The profile is loaded exactly as exported — progress, history, streaks, everything intact. Use this to:

→
Move between devices
Export on desktop, import on mobile. The file is everything.
→
Recover from a wipe
If localStorage is cleared (browser reset, private browsing), import your last export to restore.
→
Share a profile template
Export a baseline profile (zero sessions, specific curriculum) and share it as a starter pack.

Importing a Pack

A curriculum pack is a JSON array of lesson objects. Minimum required fields: id and title. The importer adds missing runtime fields (history, status, session_count, confidence) automatically. As of v1.8, it reports exactly how many lessons were added and how many were skipped (already existed or missing required fields).

Storage Health

The top bar shows a storage health indicator. If it's amber or red, your localStorage is approaching capacity. Export and consider removing old session history from lessons you've already mastered.

💡 Backup cadence — Export after any intensive session, and always before clearing browser data. The auto-export prompt fires every 5 sessions, but don't rely on it.
Chapter 07 · Tips & Advanced
Tips &
Advanced Use
Patterns and techniques that make the system work harder for you — from prompt tuning to multi-model strategy.

Profile Setup is Leverage

The single highest-impact thing you can do is fill in Role and Context properly. As of v1.8, these drive the example context in every prompt you generate. A tutor who knows you're an RPA Developer building billing automation at a telecom will give you regex examples from COBOL field parsing — not from web scraping.

Use the Prompt Override

For any lesson, you can set a Prompt Override — this replaces the entire generated prompt with exactly what you write. Use this for:

— Lessons that need Socratic dialogue instead of the TEACH/TEST flow
— Topics where you want to start from a code sample, not first principles
— Lessons you've rebuilt from scratch for a specific use case

Multi-Model Strategy

Claude is the default and handles the state machine most reliably — it respects the HARD STOP. GPT tends to jump to Phase 2 early; adding "strictly follow the state machine" at the top helps. Gemini benefits from its large context window for multi-part topics. Local models (Ollama, LM Studio) need the brevity constraint the prompt already adds — but reduce max tokens if responses are still long.

NotebookLM Mode

NotebookLM is fundamentally different from the other four options. It does not run the two-phase state machine. It generates a single-shot, source-grounded prompt that instructs NotebookLM to answer only from documents you have uploaded — with citations back to specific passages.

What you need to do before using it:

  1. Go to notebooklm.google.com and create a free notebook (requires a Google account).
  2. Upload your source material for the lesson topic. The prompt will be useless without this — NotebookLM only answers from what you give it. Good sources include:
    • Concept lessons — textbook chapters, official docs, whitepapers, or any PDF/article covering the topic
    • RPA / tool lessons — Automation Anywhere documentation, your own bot code exports, internal SOPs, AA360 JSON samples
    • Code literacy lessons — code snippets, your actual scripts, AI-generated code you want to analyse
    • Domain-specific lessons — any internal document, spec, or reference that maps to your actual work
  3. Copy the generated prompt from the trainer (it will say INSTRUCTIONS FOR NOTEBOOKLM SESSION at the top).
  4. Paste it into the NotebookLM chat panel.
  5. NotebookLM will answer with inline citations — every claim traced to a specific passage in your uploaded sources.
  6. Log the session manually using the quick log buttons (Solid / Shaky / Confused) — there is no results block to parse.

Why use it? NotebookLM grounds every answer in your actual source material, not in general training data. This is especially valuable for auditing your own documents, reviewing internal specs, or working through proprietary content you cannot paste into a public LLM.

The Bloom level is carried over. The test question in the NotebookLM prompt escalates automatically based on your session count and confidence — the same logic as the standard prompt.

Re-running a Lesson

You can run the same lesson multiple times. Each session logs independently. Confidence is always updated to the latest session value — it doesn't average. If you go from 4 back to 2 on a re-run, your confidence drops accordingly. This is intentional: the system reflects your current state, not your best-ever state.

The Onboarding Tour

Hit the ? button in the top bar to replay the four-step onboarding tour at any time. It covers the core workflow in under 90 seconds.

Quick Confidence Pips

In a lesson's detail view, click any of the five dots in the Your Confidence section to set confidence directly without logging a full session. This is useful for lessons you've studied outside the app and just want to mark accurately.
